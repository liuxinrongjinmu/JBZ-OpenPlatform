### 2.2 语雀源端调研结果

#### 商家版知识库（可访问首页）
- 公开可访问首页，能获取到知识库概述、协作者列表
- 文档目录包含：解决方案、1.2.第三方商城接入、接入指南、通用接口等模块
- 深入文档页（如 `/staff-rq30em/api/nb6461`）触发滑块登录验证
- **结论**：通过 WebFetch 无法直接获取全部151篇文档内容

#### 供应商知识库（可访问性待确认）
- 首页仅返回"👋 欢迎来到知识库"占位内容
- 可能该知识库为空、或为私有需登录、或内容在子目录
- **结论**：需要用户提供更多信息确认

### 2.3 语雀内容提取方案对比

| 方案 | 认证 | 优点 | 缺点 | 适用性 |
|---|---|---|---|---|
| A. 官方API（X-Auth-Token） | 需Token | 官方稳定、限流明确、结构化数据 | 需用户Token；表格/画板支持有限 | ⭐⭐⭐⭐⭐ |
| B. 网页爬取+URL后缀法 | 无需Token（公开文档） | 零配置 | 反爬严，易触发滑块；私有库不可用 | ⭐⭐ |
| C. yuque-dl 等开源工具 | Cookie或无需 | 开箱即用、保留目录、下载图片 | 依赖工具维护 | ⭐⭐⭐⭐ |
| D. 浏览器扩展（YuqueOut） | 复用登录态 | 支持画板/表格多格式 | 手动操作 | ⭐⭐⭐ |

**推荐方案**：A+C 组合
- 使用官方API获取结构化目录与文档正文（最稳定）
- 必要时辅以 yuque-dl 工具处理图片本地化

### 3.3 关键技术决策点（待用户确认）

#### 决策1：语雀认证方式
- **选项A**：用户提供官方API Token（推荐，最稳定）
  - 获取路径：语雀 → 头像 → 个人设置 → Token → 创建令牌（需 read:repo, read:doc 权限）
- **选项B**：用户提供登录Cookie（`_yuque_session`）
- **选项C**：用户在本地运行 yuque-dl 工具导出后，再交由本项目处理
- **选项D**：用户直接导出Markdown压缩包给我处理

#### 决策2：目标平台技术栈
- **选项A**：VitePress（推荐，Vue生态，适合API文档，支持热更新、搜索、侧边栏）
- **选项B**：Docsify（轻量，无需构建，运行时渲染）
- **选项C**：Docusaurus（React生态，功能丰富但较重）
- **选项D**：自研 FastAPI + Jinja2（与用户技术栈Python一致）
- **选项E**：其他（用户指定）

#### 决策3：图片存储策略
- **选项A**：本地静态资源（`/public/images/`，随仓库部署）—— 推荐
- **选项B**：上传至对象存储（OSS/S3/COS）后替换链接
- **选项C**：保留语雀原始CDN链接（不推荐，有时效性风险）

#### 决策4：内嵌链接处理
- **选项A**：语雀内部链接 → 转为相对路径（推荐）
- **选项B**：保留原始绝对链接
- **选项C**：删除内部链接，仅保留文字

#### 决策5：部署方式
- **选项A**：Docker Compose 一键部署（推荐，符合用户偏好）
- **选项B**：静态站点部署至 CDN/Nginx
- **选项C**：Vercel/Netlify 等PaaS
- **选项D**：服务器裸部署

#### 决策6：迁移性质
- **选项A**：一次性迁移（推荐，迁移完成后语雀作为归档）
- **选项B**：增量同步（建立定时任务持续同步语雀更新）

## 五、项目特性规范

### 5.1 技术约束
- 操作系统：macOS（开发环境），目标部署环境待确认
- 包管理：Python用pip+requirements.txt；Node用npm
- 敏感信息：API Token/Cookie 必须放 `.env`，禁止提交git
- 代码规范：函数必须有注释（docstring），符合用户5S规范

### 5.2 质量标准
- 内容完整性：原文档100%覆盖（文字、代码、图片、链接）
- 格式一致性：与语雀原始排版保持一致
- 可用性：迁移后所有内部链接可达，图片可显示
- 性能：首屏加载 < 3s，搜索响应 < 500ms

### 5.3 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 语雀反爬触发滑块 | 无法获取内容 | 使用官方API Token |
| 图片CDN链接失效 | 图片无法显示 | 全部下载本地化 |
| 画板/思维导图无法导出 | 内容缺失 | 降级为截图或提示文字 |
| 供应商库不可访问 | 范围缺失 | 与用户确认状态 |
| 内部链接断裂 | 导航异常 | 自动扫描修复 |
