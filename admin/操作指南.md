## 1. 系统概述

管理后台是聚宝赞开放平台文档站点的内容管理系统，您可以通过它完成以下操作：

- **文档管理**：新建、编辑、删除文档（Markdown 格式）
- **侧边栏管理**：配置文档站点的左侧导航菜单
- **图片管理**：上传和管理文档中使用的图片资源
- **站点构建**：将修改后的文档和侧边栏配置发布到公网站点

### 1.1 访问地址

| 功能 | 地址 |
|------|------|
| 管理后台 | `https://doc.jbzyun.cn/admin/#/` |
| 文档站点（商家版） | `https://doc.jbzyun.cn/merchant/` |
| 文档站点（供应商版） | `https://doc.jbzyun.cn/supplier/` |

### 1.2 页面导航

登录后，左侧菜单包含以下功能入口：

- **仪表盘**：查看文档总数、构建状态，触发重新构建
- **商家版文档**：管理商家版（merchant）文档的列表与编辑
- **供应商版文档**：管理供应商版（supplier）文档的列表与编辑
- **商家版侧边栏**：管理商家版文档站点的左侧导航菜单
- **供应商版侧边栏**：管理供应商版文档站点的左侧导航菜单
- **图片管理**：上传、浏览、删除文档中使用的图片

> *(截图说明：登录后仪表盘首页概览，左侧菜单栏展示全部功能入口)*

## 2. 文档编辑规范

### 2.1 文档标题规范

- **必填项**：每篇文档必须有标题
- **长度限制**：不超过 200 个字符
- **命名建议**：使用简洁明确的中文标题，如「订单查询接口」「支付回调说明」
- **格式要求**：系统会自动在文档头部生成 YAML frontmatter 存储标题，无需手动编写

### 2.2 内容结构层级

文档内容使用 Markdown 语法编写，支持以下标题层级：

```markdown
# 一级标题（文档主标题，通常与 frontmatter title 一致）
## 二级标题（章节标题）
### 三级标题（小节标题）
#### 四级标题（子小节标题）
```

**推荐结构**：

```markdown
## 概述
简要介绍功能或接口的用途。

## 接口地址
说明请求方式、URL 等信息。

## 请求参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| ...    | ...  | ...  | ...  |

## 返回示例
```json
{ ... }
```

## 错误码说明
| 错误码 | 说明 |
|--------|------|
| ...    | ...  |
```

### 2.3 文本排版要求

| 元素 | 语法 | 说明 |
|------|------|------|
| 加粗 | `**文字**` | 用于强调关键词 |
| 斜体 | `*文字*` | 用于辅助说明 |
| 行内代码 | `` `code` `` | 用于参数名、字段名、文件路径 |
| 代码块 | ` ```语言 换行 代码 换行 ``` ` | 用于示例代码 |
| 链接 | `[文字](URL)` | 用于引用外部资源 |
| 图片 | `![](/images/xxx.png)` | 用于插入图片 |
| 表格 | 见上方示例 | 用于参数和字段说明 |
| 分隔线 | `---` | 用于章节分隔 |

### 2.4 图片插入标准

**上传方式**：

1. 在左侧菜单进入「图片管理」
2. 点击「上传图片」按钮，选择本地图片文件
3. 上传成功后，系统会返回 Markdown 格式的图片引用代码

> *(截图说明：图片管理页面，展示上传按钮和已上传图片列表)*

**支持格式**：PNG、JPEG、GIF、SVG、WebP

**文件大小限制**：单张不超过 5MB

**引用方式**：

```markdown
![](/images/接口示例_1712345678901.png)
```

**注意事项**：
- 上传后文件名会自动清理（特殊字符替换为下划线），并追加时间戳避免重名
- 图片存储路径为 `docs/public/images/`
- 引用路径固定为 `/images/文件名`

### 2.5 链接添加规则

**站内文档链接**（推荐相对路径）：

```markdown
[订单查询接口](/merchant/abc123def456.md)
```

**外部链接**：

```markdown
[聚宝赞官网](https://www.jubaozan.cn)
```

**侧边栏链接**：在侧边栏管理中通过下拉选择关联已有文档，系统会自动生成正确的链接路径。

### 2.6 特殊内容注意事项

**绝对禁止**在正文中直接出现以下原始 HTML 标签（VitePress 构建会报错）：

| 禁止的写法 | 正确的写法 |
|------------|------------|
| `<script>` | `&lt;script&gt;` |
| `</script>` | `&lt;/script&gt;` |
| `<template>` | `&lt;template&gt;` |
| `</template>` | `&lt;/template&gt;` |
| `<style>` | `&lt;style&gt;` |
| `</style>` | `&lt;/style&gt;` |

> **重要提醒**：即使这些标签出现在 Markdown 代码块（三个反引号）里面，也需要转义！VitePress 会把代码块中的标签也当成真实的 Vue 组件块来处理。

**HTML 标签必须闭合**：

```markdown
<!-- 错误 -->
<font color="red">重要提示

<!-- 正确 -->
<font color="red">重要提示</font>
```

## 3. 侧边栏配置流程

侧边栏是文档站点的左侧导航菜单，决定了用户在站点上看到的文档目录结构。

### 3.1 侧边栏管理页面概览

进入「商家版侧边栏」或「供应商版侧边栏」后，可以看到当前完整的菜单树结构：

> *(截图说明：侧边栏管理页面，展示树形菜单结构，每个节点显示名称、关联链接、操作按钮)*

菜单树中的图标含义：

- 📁 — 父节点（分组菜单，可展开/收起子节点）
- 📄 — 叶子节点（独立菜单项，点击后跳转到对应文档）

### 3.2 添加根节点

1. 点击页面右上角「+ 添加根节点」按钮
2. 在弹出的对话框中填写节点信息

> *(截图说明：新增根节点弹窗，显示节点名称输入框和关联文档下拉选择器)*

### 3.3 添加子节点

1. 在已有节点右侧点击「+」按钮
2. 在弹出的对话框中填写子节点信息

### 3.4 编辑节点

1. 在已有节点右侧点击「✎」编辑按钮
2. 修改节点名称或关联文档
3. 点击「确定」保存

### 3.5 删除节点

1. 在已有节点右侧点击「✕」删除按钮
2. 在弹出的确认框中点击「确认」
3. **注意**：删除父节点会同时删除其下所有子节点，请谨慎操作

### 3.6 调整菜单顺序（上移/下移）

菜单项的显示顺序可通过每个节点右侧的「↑」「↓」按钮调整：

1. 找到需要调整顺序的菜单项，点击「↑」与上一项交换位置，点击「↓」与下一项交换位置
2. 调整后**立即实时保存生效**，无需额外保存操作
3. 已位于最顶部/最底部时继续点击会提示移动失败，属正常现象

**说明**：

- 排序在同层级内进行，可将子菜单整体随父节点移动，也可在同级菜单之间调整先后
- 排序结果直接写回侧边栏配置，前台文档站点的菜单显示顺序同步变化（公网站点需重新构建后更新）

### 3.7 侧边栏结构限制

| 限制项 | 值 | 说明 |
|--------|-----|------|
| 节点名称长度 | 最多 200 字符 | 建议控制在 20 字以内 |
| 链接长度 | 最多 200 字符 | 系统自动生成，一般不需要手动填写 |
| 菜单树层级 | 最多 5 层 | 超过 5 层的嵌套会导致菜单保存失败 |
| 菜单树总大小 | 最多 2MB | 正常使用不会达到此限制 |

### 3.8 配置项说明

**节点名称（text）**：显示在侧边栏菜单中的文本，必填。

**关联文档（link）**：该菜单项指向的文档。可以通过下拉框选择已有文档，系统自动生成链接路径。也可以选择「不关联文档」，则该节点作为纯菜单分组（父节点），仅用于组织子菜单项，点击不跳转。

**折叠状态（collapsed）**：父节点的默认展开/收起状态，系统自动管理，无需手动设置。未设置时默认为展开状态。

### 3.9 完整配置示例

下面是商家版侧边栏的典型配置示例：

```javascript
export default {
  "/merchant/": [
    {
      "text": "接入指南",
      "collapsed": false,
      "items": [
        {
          "text": "快速开始",
          "link": "/merchant/abc123def456.md"
        },
        {
          "text": "认证说明",
          "link": "/merchant/xyz789uvw012.md"
        }
      ]
    },
    {
      "text": "接口文档",
      "collapsed": false,
      "items": [
        {
          "text": "商品相关",
          "collapsed": true,
          "items": [
            {
              "text": "商品列表查询",
              "link": "/merchant/prod001abcde.md"
            },
            {
              "text": "商品详情查询",
              "link": "/merchant/prod002fghij.md"
            }
          ]
        },
        {
          "text": "订单相关",
          "collapsed": true,
          "items": [
            {
              "text": "订单创建",
              "link": "/merchant/ord001klmno.md"
            }
          ]
        }
      ]
    }
  ]
}
```

对应的菜单树展现效果：

```
📁 接入指南
  📄 快速开始
  📄 认证说明
📁 接口文档
  📁 商品相关
    📄 商品列表查询
    📄 商品详情查询
  📁 订单相关
    📄 订单创建
```

## 4. 表单字段填写指引

### 4.1 文档编辑页

| 字段 | 是否必填 | 格式要求 | 限制 |
|------|----------|----------|------|
| 标题 | **必填** | 纯文本，建议中文 | 不超过 200 字符 |
| 正文 | 可选 | Markdown 语法 | 不超过 500KB |

> *(截图说明：文档编辑页全貌，标注标题输入框和正文编辑区)*

### 4.2 新建文档页

| 字段 | 是否必填 | 格式要求 | 限制 |
|------|----------|----------|------|
| 标题 | **必填** | 纯文本 | 不超过 200 字符 |
| 正文 | 可选 | Markdown 语法 | 不超过 500KB |

文档 ID（文件名）由系统自动生成，格式为 12 位小写字母+数字组合（如 `abc123def456`），无需手动填写。

### 4.3 侧边栏节点编辑弹窗

| 字段 | 是否必填 | 格式要求 | 限制 |
|------|----------|----------|------|
| 节点名称 | **必填** | 纯文本 | 不超过 200 字符 |
| 关联文档 | 可选 | 下拉选择已有文档 | — |
| 自定义链接 | 可选 | 格式如 `/merchant/xxx.md` | 不超过 200 字符 |

**关联文档与自定义链接关系**：
- 选择「关联文档」后，链接自动填充，自定义链接无效
- 选择「不关联文档」后，可手动填写自定义链接（一般不推荐）
- 父节点（有子节点的菜单分组）不应关联文档

### 4.4 图片上传

| 限制项 | 值 |
|--------|-----|
| 支持格式 | PNG、JPEG、GIF、SVG、WebP |
| 文件大小 | 不超过 5MB |
| 文件名 | 自动清理特殊字符，追加时间戳 |

## 5. 保存机制说明

### 5.1 手动保存

**操作方式**：

1. 点击编辑页右上角绿色的「保存」按钮
2. 使用快捷键 `Ctrl + S`（Windows）或 `Cmd + S`（Mac）

**保存状态提示**：

| 状态 | 按钮显示 | 提示信息 |
|------|----------|----------|
| 保存中 | 「保存中...」灰色不可点击 | — |
| 保存成功 | 「保存」按钮恢复 | 页面顶部显示绿色「已保存」横幅（3秒后自动消失） |
| 新建成功 | 页面自动跳转 | URL 变为 `#/documents/.../edit/文档ID`，可继续编辑 |

> *(截图说明：保存成功时页面顶部的绿色「已保存」提示条)*

### 5.2 保存失败处理

保存失败时，系统会根据不同情况展示不同的错误提示：

**内容校验失败（黄色警告框）**：

> *(截图说明：保存失败时的黄色校验错误提示框，包含错误数量、每个错误的行号标记和修改建议)*

警告框包含以下信息：
- 错误总数和概要说明
- 每个错误的**具体行号**（橙色标签标注）
- 错误的**详细原因描述**
- **「怎么改」**：中文修改建议

**其他保存失败**：

| 错误场景 | 提示信息 |
|----------|----------|
| 标题为空 | 「请输入文档标题」 |
| 未登录 | 「登录已过期，请刷新页面重新登录」 |
| 文档不存在 | 「文档不存在，可能已被删除」 |
| 服务器错误 | 「服务器内部错误，请稍后重试」 |
| 网络中断 | 「网络错误，请检查连接」 |

### 5.3 侧边栏保存

**新增/编辑节点**：
- 点击弹窗「确定」按钮后立即保存到文件
- 校验失败时，页面顶部显示黄色警告框，列出所有无效链接及修改建议

> *(截图说明：侧边栏保存失败时的黄色校验错误提示框，列出指向不存在文档的链接)*

**注意**：侧边栏的修改是一个节点一个节点保存的，每次弹窗确认都是一次独立的保存操作，无需额外的「全部保存」按钮。

## 6. 构建流程详解

### 6.1 什么是构建

构建是将您编辑的 Markdown 文档和侧边栏配置，通过 VitePress 工具生成为浏览器可直接访问的静态网页（HTML/CSS/JS）的过程。

> **工作流**：编辑文档/侧边栏 → 保存 → 点击「重新构建」→ 等待构建完成 → 公网站点更新

### 6.2 触发方式

**方式一：仪表盘触发（推荐）**

1. 进入「仪表盘」页面
2. 在右侧「重新构建」区域点击蓝色「重新构建」按钮
3. 等待构建完成

> *(截图说明：仪表盘构建区域，显示上次构建状态和「重新构建」按钮)*

**触发限制**：
- 同一时间只能运行一个构建任务
- 如果已有构建在进行中，会提示「正在构建中，请稍后再试」

### 6.3 构建过程

**执行步骤**：

1. 生成文档索引（统计所有文档）
2. 编译 Vue 客户端和服务端代码包
3. 渲染所有页面为静态 HTML
4. 同步构建产物到 Nginx 目录（生产环境）

> *(截图说明：构建过程中黑色终端风格日志区域，实时显示构建日志)*

**实时日志**：
构建过程中，日志区域会实时显示 `vitepress build` 的标准输出，包括：
- 构建阶段信息（building / rendering）
- 警告信息（黄色文字）
- 错误信息（红色文字）

### 6.4 构建结果

**构建成功**：

- 日志最后一行显示：`✅ 构建完成，耗时 X.Xs，网站已更新`
- 仪表盘构建状态更新为「成功 (X.Xs)」
- 公网站点内容已更新

**构建失败**：

- 日志显示：`❌ 构建失败 (退出码: 1)`
- 仪表盘构建状态更新为「失败」
- 公网站点保持上次成功构建的版本，不受影响
- **常见失败原因**：某篇文档内容存在语法错误（详见[校验规则说明](#7-校验规则说明)）

### 6.5 构建状态查询

每次进入「仪表盘」页面，系统会自动加载最新的构建状态，包括：

- 上次构建时间
- 构建结果（成功/失败）
- 构建耗时

### 6.6 构建注意事项

1. **保存 ≠ 发布**：保存文档后需要执行构建，公网站点才会更新
2. **多次修改可一次构建**：修改多篇文档或侧边栏后，只需执行一次构建即可
3. **构建失败不影响线上**：失败时线上站点保持上一次成功版本
4. **构建耗时约 3-10 秒**：取决于文档数量

## 7. 校验规则说明

系统在保存文档和侧边栏配置时，会自动进行多项校验，确保内容能够通过 VitePress 构建。

### 7.1 文档内容校验

校验时机：**点击「保存」按钮时即时校验**

| 校验项 | 规则 | 校验失败时的提示 |
|--------|------|------------------|
| 标题非空 | 标题不能为空 | 「请输入文档标题」 |
| 标题长度 | ≤ 200 字符 | 「标题不能超过 200 个字符」 |
| 正文长度 | ≤ 500KB | 「内容不能超过 500KB」 |
| `<script>` 标签 | 正文中禁止出现未转义的 `<script>` | 显示行号 + 提示改为 `&lt;script&gt;` |
| `<template>` 标签 | 正文中禁止出现未转义的 `<template>` | 显示行号 + 提示改为 `&lt;template&gt;` |
| `<style>` 标签 | 正文中禁止出现未转义的 `<style>` | 显示行号 + 提示改为 `&lt;style&gt;` |
| HTML 标签闭合 | 所有 HTML 开标签必须有对应的闭标签 | 显示行号 + 提示添加闭合标签或转义 |

> *(截图说明：校验失败时黄色警告框示例，显示多个错误的行号、错误描述和修改建议)*

## 8. 常见问题处理

### Q1：保存文档时提示「文档内容存在 X 个问题」

**原因**：文档正文中包含了未被转义的 `<script>`、`<template>`、`<style>` 标签，或存在未闭合的 HTML 标签。

**解决方法**：
1. 根据黄色警告框中的行号，找到对应的问题行
2. 按照「怎么改」中的建议进行修正：
   - 将 `<script>` 改为 `&lt;script&gt;`
   - 将 `</script>` 改为 `&lt;/script&gt;`
   - 同理处理 `<template>` 和 `<style>` 标签
   - 为未闭合的 HTML 标签添加对应的关闭标签
3. 修正后重新点击「保存」

> **特别提醒**：即使 `<script>` 标签出现在 Markdown 代码块（三个反引号）里面，也必须转义！

### Q2：保存侧边栏节点时提示「链接指向不存在的文档」

**原因**：该菜单节点关联的文档文件在系统中不存在（可能是被删除了，或从未创建过）。

**解决方法**：
1. 先在「文档列表」中创建对应的文档
2. 或修改菜单节点，选择其他已存在的文档
3. 或将该节点设为「不关联文档」变成纯分组节点

### Q3：点击构建后长时间无响应或构建失败

**可能原因及解决方法**：

| 原因 | 解决方法 |
|------|----------|
| 有文档保存时跳过了校验（历史遗留文件） | 查看构建日志，定位报错文件，回到编辑页重新保存（此时系统会触发最新校验） |
| 侧边栏有死链 | 进入侧边栏管理，检查是否有链接指向被删除的文档 |
| 服务器资源不足 | 稍等片刻后重试 |
| 构建进程卡死 | 刷新页面，重新点击构建 |

> **排查技巧**：如果构建日志显示 `compiler-sfc` 或 `Element is missing end tag` 错误，说明某篇文档内容有语法问题。可根据日志中的文件名定位问题文档。

### Q4：公网文档标题不显示或显示异常

**原因**：可能是旧版系统导致文档的 frontmatter 被损坏。

**解决方法**：
1. 在管理后台打开该文档进入编辑页
2. 检查标题栏是否正常显示
3. 重新点击「保存」
4. 执行重新构建

### Q5：新建文档后，在侧边栏管理中找不到该文档

**可能原因**：
- 文档下拉框只加载前 1000 篇文档，如果超出此数量，可通过搜索文档标题定位
- 确认是否正确选择了对应的目录（商家版/供应商版）

**解决方法**：在侧边栏编辑弹窗中，从「关联文档」下拉列表搜索文档标题关键词即可。

### Q6：编辑器左右分栏太窄/太宽

**解决方法**：使用鼠标拖动编辑区和预览区之间的分隔条，可以自由调节左右宽度。将鼠标悬停在分隔条上，光标变为左右箭头（↔）后，按住左键拖动即可。

> *(截图说明：鼠标悬停在编辑器分隔条上，显示左右箭头光标)*

### Q7：忘记保存就关闭了页面

**当前机制**：系统没有自动保存功能，所有修改需手动保存。**请养成经常按 `Ctrl+S` / `Cmd+S` 保存的习惯**。

### Q8：删除了文档，但侧边栏还有该链接

**原因**：删除文档不会自动清理侧边栏中的引用链接。

**解决方法**：
1. 进入侧边栏管理页面
2. 找到引用已删除文档的菜单节点
3. 删除该节点或修改为其他有效文档
4. 保存侧边栏

### Q9：构建成功但公网站点没有更新

**可能原因**：
- 浏览器缓存了旧版本页面
- Nginx 同步延迟（极少见）

**解决方法**：
1. 使用浏览器的「硬刷新」功能（`Ctrl+Shift+R` / `Cmd+Shift+R`）
2. 或在浏览器中打开无痕/隐私窗口访问站点
3. 等待 1-2 分钟后重试

### Q10：登录后很快被踢出需要重新登录

**原因**：会话有效期机制。长时间不操作后，系统会自动清除登录状态以保证安全。

**解决方法**：重新输入管理员密码登录即可。
