## 业务模块

- **接入指南**：ERP对接、APP对接、H5直播间嵌入
- **通用接口**：店铺信息、省市区、商品类目、订单类型、支付渠道
- **会员信息**：会员查询、会员等级、会员手机号
- **商品接口**：商品CRUD、SKU管理、商品上下架
- **订单接口**：订单查询、发货、退款、售后、核销
- **营销接口**：优惠券、积分、第三方会员同步
- **门店管理**：门店CRUD、店员、片区、客户归属
- **积分管理**：积分查询、积分充值、积分扣减
- **消息推送**：订阅消息、订单消息、会员消息
- **数据统计**：云店数据汇总、云店数据详情
