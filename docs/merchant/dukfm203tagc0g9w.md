# 1.5.第三方订单同步到聚宝赞流程

---

### 不同订单类型状态流转

| 订单类型 | 状态流转 |
| --- | --- |
| 实物商品-快递配送 | 待付款 → 待发货 → 已发货 → 已完成 |
| 实物商品-门店配送 | 待付款 → 待配送 → 已发货 → 已完成 |
| 实物商品-门店自提 | 待付款 → 待提货 → 已完成 |
| 虚拟商品-自动核销 | 待付款 → 已完成 |
| 虚拟商品-商家核销 | 待付款 → 待核销 → 已完成 |

ps: 订单状态不可逆转
