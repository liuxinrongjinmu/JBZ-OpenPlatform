# 5.3.1.订单批量商品发货

---

**接口说明**：多订单批量发货，可根据SKU拆单发货，<font style="color:#DF2A3F;">注意：此接口多次调用会产生多次发货记录，不会覆盖原有的发货信息</font>

**请求方式**：POST（HTTPS）

**请求头**：`Content-Type：application/json`

**请求地址**：[https://api.c3tech.cn/oauthentry/v2/trades/orders/goods/batchDelivery?access_token=[token]](https://api.c3tech.cn/oauthentry/trades/orders/batchDelivery?access_token=%5Btoken%5D)

**参数说明**：

| 参数 | | 类型 | 必传 | 示例值 | 说明 |
| --- | --- | --- | --- | --- | --- |
| items | | List | Y |  | 发货信息 |
|  |   ├ orderNo | String | Y | YT | 订单号 |
|  |   ├ goodsId | String | Y | 4456889 | 商品ID |
|  |   ├ skuCode | String | Y | 1222-8888 | SKU编码 |
|  |   ├ expressCode | String | Y | YT2355422 | 物流公司编码 |
|  |   ├ expressNo | String | Y | 123123 | 快递单号 |
|  |   ├ expressName | String | Y | 圆通速递 | 物流公司名称 |
|  |   ├ expressTime | String | N | 2024-07-12 12:00:00 | 发货时间 |
|  |   └ quantity | Integer | N | 1 | 发货数量（默认为购买数量） |

_**支持物流公司编码(外部链接)**__：__/

### 接口调用Demo

```http
Post https://api.c3tech.cn/v2/oauthentry/trades/orders/goods/batchDelivery?access_token=[token]
{
  "items": [
    {
      "expressCode": "YTO",
      "expressName": "圆通速递",
      "expressNo": "YT7478245407054",
      "expressTime": "2024-07-12 12:00:00",
      "goodsId": 335738814,
      "orderNo": "S20240710160529892832676",
      "quantity" : 1,
      "skuCode": "01001-02002"
    }
  ]
}
```
