# 10.7会员余额查询

---

**接口说明**：会员余额查询

**请求方式**：POST（HTTPS）

**请求头**：`Content-Type：application/x-www-form-urlencoded`

**请求地址**：https://api.c3tech.cn/oauthentry/user/queryBalance?access_token=[token]

**请求参数**

| 名称 | 必选 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| access_token | Y | String | 44c6f2ac-695f-4b00-8d80-249986f5c466 | 授权令牌 |
| agentId | Y | integer | | 会员id |

**响应参数**

_Body:_

| 名称 | 必选 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| response | 否 | object | | 响应数据 |
|   ├ code | 否 | string | | 返回码 |
|   ├ msg | 否 | string | | 返回信息 |
|   └ result | 否 | object | | 响应结果 |
|     ├ balance | 是 | BigDecimal | | 余额 |
| traceId | 否 | string | | 请求标识 |

**错误响应示例**：

```json
{
  "error_response": {
    "code": "1009",
    "msg": "用户不存在"
  }
}
```
