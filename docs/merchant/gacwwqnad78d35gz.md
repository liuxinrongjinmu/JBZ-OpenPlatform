# 7.16.积分消息

---

**接口说明**：用户积分变更详情：SCORE_BATCH_CHANGE_DETAIL

**请求方式**：POST（HTTPS）

**请求头**：`Content-Type：application/json`

**请求地址**：订阅方提供（第三方企业提供）

###  积分事件Msg参数说明

List&lt;UserScoreMessage&gt;

| 参数 | 类型 | 示例 | 必传(Y/N) | 说明 |
| --- | --- | --- | --- | --- |
| sjid | Long | 9601 | Y | 商家ID |
| agentid | Long | 112234 | Y | 用户ID |
| orderid | String | 1 | Y | 用户编号 |
| nick | String | | N | 昵称 |
| scoreType | Integer | 1 | Y | 积分类型《积分类型字典》 |
| scoreBalance | Double | | Y | 积分余额 |
| changeScore | Double | | Y | 积分变更值(扣减为负值) |
| bizCode | String | | Y | 业务单号(可用作幂等) |
| updateAt | Date | | Y | 变更时间 |

### 公共请求示例

```json
{
  "id": "112344",
  "client_id": "shex888",
  "type": "SCORE_BATCH_CHANGE_DETAIL",
  "msg": "UrlEncode(积分msg)",
  "sjid": 86,
  "sign": "sign",
  "version": "1.0"
}
```
