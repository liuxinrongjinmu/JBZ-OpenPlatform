# 2.3.鉴权认证

## **一、鉴权认证机制**

本文档主要针对HTTP API调用者，开放平台使用[OAuth 2.0](https://oauth.net/2/)授权调用开放API。 调用之前使用client_id和client_secret通过凭证接口获取access_token信息，调用API时必须在请求中携带授权令牌 access_token 信息。（**如果对**[**OAuth 2.0协议**](http://www.ruanyifeng.com/blog/2019/04/oauth-grant-types.html)**不了解，可以先了解**[**OAuth 2.0协议**](http://www.ruanyifeng.com/blog/2019/04/oauth-grant-types.html)）

## **三、获取令牌接口（access_token）：**

### **1.1 获取授权码**

**请求方式**：GET（HTTPS）

**请求地址**：https://api.c3tech.cn/oauth/authorize?client_id=test&response_type=code&redirect_uri=http://third.com/callback

<details class="lake-collapse"><summary id="u3532a01f"><span class="ne-text">测试环境体验授权</span></summary><p id="ucc0dad34" class="ne-p"><span class="ne-text"> a、体验连接 https://testapi.jubaozan.cn/oauth/authorize?client_id=boboxia&amp;response_type=code&amp;redirect_uri=http://api-test.boboxia.cc/auth/jbz/getCode</span></p><p id="ub6f922e1" class="ne-p"><span class="ne-text">b、体验登录账号请联系客服或者技术获得</span></p></details>

**参数说明**：

| 参数 | 类型 | 必传(Y/N) | 示例值 | 说明 |
| --- | --- | --- | --- | --- |
| client_id | String | Y | testclient | 聚宝赞商城颁发给开发者的应用ID |
| response_type | String | Y | code | 返回的令牌类型（固定为 “code”） |
| state | String | N | teststate | 自定义字段，用于保持请求和回调的状态，在回调时，会回传该参数。开发者可以用这个参数验证请求有效性，也可以记录用户请求授权页前的位置。可防止CSRF攻击 |
| redirect_uri | String | Y | [http://third.com/callback](http://third.com/callback) | 指明当用户授权完成之后返回的地址（授权后聚宝赞回调该地址并返回授权code) |

**返回结果**：

| 参数 | 类型 | 必传(Y/N) | 说明 |
| --- | --- | --- | --- |
| code | String | Y | code 参数可以在 redirect_uri 对应的应用后端程序中获取（过期时间：2 分钟） |

### 1.2 授权码模式获取access_token

**请求方式**：POST（HTTPS）

**请求头**：`Content-Type：application/x-www-form-urlencoded`

**请求地址**：https://api.c3tech.cn/oauth/token

**参数说明**：

| 参数 | 类型 | 必传(Y/N) | 示例值 | 说明 |
| --- | --- | --- | --- | --- |
| client_id | String | Y | testclient | 聚宝赞商城颁发给开发者的应用ID |
| client_secret | String | Y | testclientsecret | 聚宝赞颁发给开发者的应用Secret |
| grant_type | String | Y | authorization_code | 授权方式(固定为“authorization_code”) |
| code | String | Y | SJKLJD | 商家授权后聚宝赞返回的授权码（Authorization Code） |
| redirect_uri | String | Y | [http://third.com/callback](http://third.com/callback) | 授权回调地址（该值必须与获取 Authorization Code 时传递的 redirect_uri 保持一致。注意：redirect_uri 不要urlencode操作） |

**返回结果**：

| 参数 | 类型 | 必传(Y/N) | 说明 |
| --- | --- | --- | --- |
| access_token | String | Y | 可用于调用 API 的 access_token，有效7天；access_token失效前可通过refresh_token刷新延长，刷一次延长7天 |
| expires_in | Number | Y | access_token 的有效时长，单位：秒（过期时间：7天） |
| token_type | String | Y | 令牌类型 |
| refresh_token | String | Y | 用于延长 access_token 有效时间的刷新令牌（过期时间：28 天,refresh_token不能重复使用，调用刷新接口后会返回新的refresh_token，注意保存新refresh_token） |
| shopId | number | Y | 授权方ID，根据授权模式返回供应商/商家ID |
| platform | String | Y | 授权方类型;   JBZ:商家   SUP:供应商 |

注意：请求不要携带cookie

## **四、刷新令牌 (Refresh Token)：**

**请求方式**：POST（HTTPS）

**请求头**：`Content-Type：application/x-www-form-urlencoded`

**请求地址**：https://api.c3tech.cn/oauth/token
注： 刷新后,旧access_token会保留5分钟有效期(未过期情况).

**参数说明**：

| 参数 | 类型 | 必传(Y/N) | 示例值 | 说明 |
| --- | --- | --- | --- | --- |
| client_id | String | Y | testclient | 聚宝赞商城颁发给开发者的应用ID |
| client_secret | String | Y | testclientsecret | 聚宝赞颁发给开发者的应用Secret |
| grant_type | String | Y | refresh_token | 授权方式(固定为“refresh_token”) |
| refresh_token | String | Y | 013c6f454917531c00c99539a0160 | 用于获得 access_token 有效时间的刷新令牌（过期时间：28 天,refresh_token不能重复使用，调用刷新接口后会返回新的refresh_token，注意保存新refresh_token） |

**返回结果**：

| 参数 | 类型 | 必传(Y/N) | 说明 |
| --- | --- | --- | --- |
| access_token | String | Y | 可用于调用 API 的 access_token，有效7天；access_token失效前可通过refresh_token换取新的access_token |
| expires_in | Number | Y | access_token 的有效时长，单位：秒（过期时间：7天） |
| token_type | String | Y | 令牌类型 |
| refresh_token | String | Y | 用于延长 access_token 有效时间的刷新令牌（过期时间：28 天,refresh_token不能重复使用，调用刷新接口后会返回新的refresh_token，注意保存新refresh_token） |
| platform | String | Y | 授权方类型;   JBZ:商家   SUP:供应商 |

注意：请求不要携带cookie
