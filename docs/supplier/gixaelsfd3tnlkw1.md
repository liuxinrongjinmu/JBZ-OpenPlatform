# 备货发货

---

<font style="color:#8A8F8D;">此文主要描述当商家产生订单，使用开放平台接口，备货发货，修改物流等。</font>

**备货**

使用订单备货接口，将订单状态改为备货中，如果备货权在分销商则不变。

此接口与以下功能保持一致，（订单 -> 订单列表 -> 备货并导出）如图：

![](/images/supplier/514282f4e72478c2.png)

您还可以使用批量取消备货接口，将订单改为待发货状态。

相关接口：

[备货](./lbh10n3f7bfrbuhr.md)

[批量备货](./hebbv26f25rvwot0.md)

[批量取消备货](./gsl917ykkcxepgwt.md)

**发货**

当您备货完成后，您可以使用发货接口，并且填写物流信息，将订单改为已发货状态。

此接口与以下功能保持一致，（订单 -> 订单列表 -> 发货）如图：

![](/images/supplier/f84eabe72e68b8b3.png)

您还可以修改已发货的商品物流信息。

**相关接口：**

[批量发货](./fdduqtyhh04wg7ad.md)

[批量覆盖物流发货](./xe11ba50p3ndsouq.md)

[修改物流](./hue2z0hywbwsb8sx.md)
