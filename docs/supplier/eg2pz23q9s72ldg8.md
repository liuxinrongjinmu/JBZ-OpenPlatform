# 接入须知

---

<font style="color:#8A8F8D;">此文主要描述供应商的第三方系统如何使用聚宝赞开放平台供应商接口，获取聚宝赞供应商系统能力，包含同步商品、商品上下架、获取订单、备货发货、退款售后等。</font>

**第三方系统需要获取供应商授权，才能调用开放平台接口。**

操作步骤：

+ 登录到第三方系统，找到聚宝赞授权按钮。
    - _<font style="color:#DF2A3F;">如果需要对接新的第三方，请联系商务。申请新的应用ID(client_id)。</font>_
    - _<font style="color:#DF2A3F;">当第三方服务对接完成后会开放授权入口。</font>_
+ 点击授权按钮。
+ 此时系统会跳转到授权页面，如图：

![](/images/supplier/aeb70ac96c20e76f.png)

+ 选择授权类型为：**供应商**，输入登录聚宝赞供应商系统的账号和密码。确认授权
+ 授权成功即可获取code。
+ 通过code获取获取token。

**相关接口：**

[认证鉴权](./afyud5gcw8gn6i19.md)

**当第三方系统获取到token后，第三方系统使用token调用聚宝赞开放平台接口。**

**注意：**

<font style="color:#DF2A3F;">token有效7天；失效前可通过refresh_token重新获取token。</font>
