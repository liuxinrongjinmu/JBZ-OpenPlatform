# 商品同步

---

<font style="color:#585A5A;">本文主要描述认证鉴权之后，如何使用开放平台接口，新增商品，修改商品，上下架商品等。</font>

### 新增商品

**前置条件：**

新增商品之前，您需要创建一个仓库。获取到返回的仓库ID。后续新增商品时需要使用。

_仓库创建完成后，在 商品 -> 仓库设置，可以看到新增的仓库，如图：_

![](/images/supplier/cbee7bb979f2fd53.png)

**相关接口：**

[仓库新增/编辑](./vyhuigpp7195luta.md)

获取全量类目信息，将商品归属到合理的类目当中。

**相关接口：**

[获取全量类目信息](./ktwigfetg7odz79h.md)

**同步商品**

调用商品新增接口，将商品同步到聚宝赞供应商系统。

新增的商品在 商品 -> 商品管理 中查询，您可以使用同步过来的<u>商品编码查询</u>，如图。

![](/images/supplier/a6aa9a19286e89ba.png)

**相关接口：**

[商品同步（新增）](./gzsyo29w7x8z38t5.md)

[商品同步（修改）](./foffig2hlto5for3.md)

**<font style="color:#DF2A3F;">注意：</font>**

+ _<font style="color:#DF2A3F;">商品使用externalGoodsId作为唯一的判断标识，同一个externalGoodsId将作为同一个商品，不同的externalGoodsId将视为不同商品。</font>_
+ _<font style="color:#DF2A3F;">同步成功的商品，默认为上架状态。</font>_

**供应商推送商品到商家**

当商品同步到供应商系统后，传入需要推送的分销商标识，调用**上架到店铺**接口，即可推送到具有绑定关系的分销商。

此推送逻辑，等同于以下操作如图（商品->商品管理->管理分销商）：

![](/images/supplier/db41540f99497001.png)

**相关接口：**

推送商品到店铺

**同步供应商与分销商的关系**

您也可以选择消息订阅机制，实时获取与分销商的关系。在需要推送商品时，传入对应的分销商标识。

**相关接口：**

[消息推送](./rq97dtuumebxeqsn.md)

_为了校验数据的合法性，我们需要约定一个防伪计算。_

[公共推送参数](./ialcoh5ofn4tuund.md)

_Msg详细内容说明：_

[SUPPLIER_RETAIL_BIND 供货商和分销商关系](./vr7odroaoo3h8kcr.md)

**<font style="color:#DF2A3F;">注意：</font>**

+ <font style="color:#DF2A3F;">一个供应商只能绑定一个消息订阅地址。</font>
+ <font style="color:#DF2A3F;">不同业务处理通过不同的业务类型区分。</font>

当商品库存需要变更，调用商品库存变更接口，库存变更会默认同步给已经推送此商品的商家。

**相关接口:**

[库存变更接口](./cz17dls64g2iegvb.md)

当商品不在售卖，您可以自行选择下架商品，调用商品下架接口，将会同步下架到已经推送此商品的商家。

**相关接口：**

[商品上下架接口](./hv4ip9btb1h94tfp.md)

**运费模板**

您也可以使用运费模板，来管理运费的计算。新增商品时，传入运费模板id，建立商品与运费模板的关系。

使用运费模板接口等同以下功能操作，如图（订单 -> 运费模板）：

![](/images/supplier/a4e9ea60cb9b7859.png)

**相关接口：**

[创建运费模板](./mv3dl2n5gm55gvq4.md)

[查询运费模板](./ukv1vhbwufzw5rh2.md)

[修改运费模板](./nsd001exbq114bos.md)

[删除运费模板](./vl2wku78p0k37vgx.md)

**商品内容**

您还可以为商品添加内容笔记，丰富商品的展示信息。

您可以调用开放平台接口创建内容，然后使用内容标识关联商品。

使用开放平台接口，等同于以下功能，如图（商品 -> 商品管理 -> 内容管理）：

![](/images/supplier/c2994a44f3722d29.png)
